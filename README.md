  Smart AgriAssist: Intelligent Philippine Farm Management & AI Decision-Support System
Smart AgriAssist is an intelligent, web-based farm management and AI-powered decision-support platform tailored specifically for the Philippine agricultural setting. It combines real-time weather monitoring, computer-vision crop disease diagnosis, and role-based administration to boost productivity and climate resilience among Filipino smallholder farmers and agricultural workers. 
 Project Overview & Framework
•	Project Title: Development of Smart AgriAssist: An Intelligent Philippine Farm Management and AI-Powered Decision-Support System 
•	Domain: Smart Agriculture, Web Development, AI-Driven Decision Support, and Agro-Meteorology 
•	Target Geography: Tailored for Philippine climate patterns and regional locations such as Western Visayas / Kabankalan City 
•	Primary Beneficiaries: Smallholder farmers, LGU agricultural extension officers, system administrators, and agriculture students 
•	Tech Stack:
o	Backend: PHP / Python (Django) 
o	Database: MySQL / PostgreSQL 
o	Frontend: HTML5, CSS3, JavaScript, and Bootstrap / Tailwind 
o	APIs & AI: Open-Meteo Weather API, Gemini AI Models (Conversational & Computer Vision) 
Objectives
Designed to address manual farm inefficiencies and streamline agricultural workflows, the project encompasses the following specific technical goals: 
•	Role-Based Access Control (RBAC): Establishes secure authentication separating System Administrators / LGU Officers and Farm Users / Farmers with custom geolocation preferences. 
•	Admin Management Console: Provides tools for system administrators to oversee user accounts, curate the Philippine Crop Catalog, configure global weather alerts, and view system analytics. 
•	Crop Growth Monitoring & Lifecycle Tracking: Tracks crop age, growth phases (e.g., Germination, Vegetative, Panicle Initiation), and estimated harvest timelines for registered field crops. 
•	AI Agri Assistant & Visual Disease Diagnosis: Utilizes conversational AI and image processing models to run multi-turn farming consultations and analyze crop leaf photos for pest/disease symptoms. 
•	Agro-Meteorology & Live Weather Integration: Connects to live weather APIs (e.g., Open-Meteo) to deliver multi-day forecasts, severe weather risk warnings, and weather-derived farming advice. 
•	Automated Task Scheduler & Multi-Channel Notifications: Delivers customizable alerts via in-app notifications, browser push alerts, and email warnings for weather risks and crop care reminders. 
Core System Modules
The platform is organized into a comprehensive suite of integrated modules: 
•	Authentication & User Management:
o	Secure login portals and user profile customization settings tailored by access level. 
•	Administrative Console & Knowledge Base:
o	Centralized governance for updating agricultural guidelines, monitoring queries, and managing system users. 
•	Intelligent Dashboard:
o	Real-time overview of active field plots, current local weather updates, and pending operational tasks. 
•	Agri AI Chat & Vision Diagnosis:
o	Instant photo-based plant health scouting paired with conversational agronomy assistance. 
•	Searchable Crop Catalog:
o	Structured agronomic reference profiles, categories, and maintenance guidelines for major commercial and regional crops. 
•	Task Scheduler & Notification Center:
o	Automated tracking of field activities and multi-channel broadcast of severe weather hazard alerts.

Scope & Development Limitations
•	Administrative Privileges:
o	Backend configurations and user database management are restricted exclusively to authorized System Administrators and LGU Officers. 
•	Connectivity Dependency:
o	Live weather forecasts and risk alerts require active internet connectivity and continuous third-party API availability (Open-Meteo). 
•	Computer Vision Constraints:
o	Visual diagnostic accuracy depends heavily on image clarity, lighting, and clear leaf/stem symptoms; deep root or non-visual pathologies are excluded. 
•	Exclusions:
o	The current development phase does not include direct e-commerce transactions, online payment gateways, hardware IoT field sensor nodes, or automated mechanical machinery controls.
