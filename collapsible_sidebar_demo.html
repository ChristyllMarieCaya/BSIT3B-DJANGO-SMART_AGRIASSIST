Key Behaviors Demonstrated

  • Hamburger Menu Toggle: Clicking the button at the top collapses the sidebar to 72px icon-only mode on desktop, or opens the mobile drawer on mobile screens.
  • Accordion Category Rows: Clicking any category smoothly expands its child items while automatically collapsing any previously open category.
  • Auto-Expand Sidebar on Click: When the sidebar is in its collapsed/icon-only state, clicking any category row automatically expands the sidebar to full width (260px) and opens its sub-items!
  • Smooth Transitions: CSS transitions handle width adjustments and sub-menu slide-downs.
  • Mobile Overlay Drawer: Includes a frosted backdrop that closes the drawer when tapped.
